# Context Atlas

The registry is `.spec/ATLAS.md`. Each entry is a sector code, a link and a short description.
Sectors: 000 cards, 100 work dispatch, 200 boundaries, 300 contracts, 400 system spec (harness),
500 project files. Slices name their sectors in `Coords: [...]`, and every code must appear in the
registry. Read a sector only when the task needs it.
